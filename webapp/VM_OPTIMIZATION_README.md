# 🚀 VM Production Optimization Guide

## Оптимизация для виртуальной машины (Production)

Этот документ содержит все оптимизации, настроенные для максимальной производительности на виртуальной машине.

### 📊 **Ключевые оптимизации**

#### 1. **Backend (Go)**
- ✅ **Оптимизированный Dockerfile** - multi-stage build с минимальным размером
- ✅ **Отключен трейсинг** - для максимальной производительности
- ✅ **Оптимизированные переменные Go** - GOMAXPROCS=4, GOMEMLIMIT=2GiB
- ✅ **Ресурсные ограничения** - 2GB RAM, 2 CPU cores
- ✅ **Оптимизированный HTTP сервер** - таймауты, буферы, заголовки

#### 2. **MySQL Database**
- ✅ **Увеличенный buffer pool** - 4GB для production
- ✅ **Оптимизированные InnoDB настройки** - log files, IO capacity
- ✅ **Улучшенные индексы** - покрывающие индексы, составные индексы
- ✅ **Ресурсные ограничения** - 6GB RAM, 3 CPU cores
- ✅ **Оптимизированный пул соединений** - 150/75 connections

#### 3. **Nginx Reverse Proxy**
- ✅ **Gzip сжатие** - для всех текстовых ресурсов
- ✅ **Кэширование статических файлов** - 1 год для assets
- ✅ **Оптимизированные upstream** - keepalive, failover
- ✅ **SSL оптимизация** - современные шифры, session cache
- ✅ **Ресурсные ограничения** - 1GB RAM, 1.5 CPU cores

#### 4. **Системные оптимизации**
- ✅ **Kernel параметры** - увеличенные лимиты соединений
- ✅ **File limits** - 65535 файловых дескрипторов
- ✅ **Docker оптимизация** - overlay2 storage, log rotation
- ✅ **Memory management** - swappiness, dirty ratios

### 🚀 **Запуск на VM**

#### Быстрый запуск:
```bash
cd webapp
./run_production_optimized.sh
```

#### Полная оптимизация VM (выполнить один раз):
```bash
sudo ./optimize_vm.sh
sudo reboot
```
